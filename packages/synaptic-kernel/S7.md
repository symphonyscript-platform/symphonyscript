**Decisions to make first** (5 minutes, before any code):

1. **`Option<SlotId>` vs `SlotId` for node/synapse pointer fields.** All slot-pointer accessors (`next_ptr`, `prev_ptr`,
   `*_synapse_head/tail`, synapse `source_ptr`/`target_ptr`, synapse chain `outgoing_*`/`incoming_*`) currently return
   `usize`, where `0` means "no slot." After S7, they return `Option<SlotId>`. None = no slot, Some(SlotId) = real slot.
   This applies uniformly — even `source_ptr`/`target_ptr` which are conceptually always Some in steady state, return
   Option for type-system honesty.

2. **`SlotId(pub NonZeroU32)` field visibility.** You already chose `pub`. That's fine — `NonZeroU32` enforces the
   invariant; field-pub lets external code recover the raw value via `slot.0.get()`. Standard newtype pattern.

3. **Construction-time capacity check.** Goes in `SimpleFreeList::create` (since it's the deepest primitive that owns
   the slot space). Add `assert!(capacity <= i32::MAX as usize, ...)` so wire conversion via `as i32` is provably
   lossless.

**Phase 0 — Foundation: extend `slot.rs`** (15 min)

Add helper methods on `SlotId`:

```rust
use std::num::NonZeroU32;

impl SlotId {
    /// Construct from a raw value. Returns `None` if `value == 0`.
    #[inline]
    pub fn new(value: u32) -> Option<SlotId> {
        NonZeroU32::new(value).map(SlotId)
    }

    #[inline]
    pub fn get(&self) -> u32 {
        self.0.get()
    }

    /// Read a slot from the wire (i32, 0 = undefined).
    #[inline]
    pub fn from_i32(value: i32) -> Option<SlotId> {
        if value <= 0 {
            None
        } else {
            Some(SlotId(unsafe { NonZeroU32::new_unchecked(value as u32) }))
        }
    }

    /// Write a slot to the wire. None becomes 0.
    #[inline]
    pub fn option_to_i32(slot: Option<SlotId>) -> i32 {
        match slot {
            Some(s) => s.get() as i32,
            None => 0,
        }
    }

    #[inline]
    pub fn to_i32(&self) -> i32 {
        self.0.get() as i32
    }
}

impl From<SlotId> for usize {
    #[inline]
    fn from(s: SlotId) -> usize {
        s.0.get() as usize
    }
}
```

The `unsafe { NonZeroU32::new_unchecked }` after the `value > 0` check is the standard pattern — a const-fold-friendly
way to skip the redundant null-check that `NonZeroU32::new` would do. Keeps the wire conversion cheap.

Update the `Display` impl that's already there (currently formats `self.0` as u16 via the old type — will compile-fail
with NonZeroU32; just change to `self.0.get()`).

After Phase 0: `slot.rs` compiles standalone, no other files touched yet.

**One pitfall to watch for.** `EntryStoreWriter::insert()` calls `self.allocator.alloc()` which now returns
`Option<SlotId>`, then immediately calls `self.tb.write(tb_start_offset + i, 0)` to zero out the new slot's region. The
`tb_start_offset` calculation goes through `calculate_struct_zone_base(... slot: SlotId, ...)`. Make sure the slot
conversion happens once at the boundary, not five times. Easy place to accidentally write `as usize` boilerplate.
